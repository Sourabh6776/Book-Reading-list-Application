# 📚 Book Reading List App

A simple, interactive web application that helps users organize and track their personal reading journey. Users can add books, manage their reading status, search their library, and keep track of their reading progress.

## ✨ Features

- **Add Books:** Add a book with its title, author, genre, and reading status.
- **Manage Reading Status:** Organize books into To Read, Reading, and Completed categories.
- **Search Books:** Find books by searching the library.
- **Filter Books:** Filter books according to their reading status.
- **Track Progress:** View total books, currently reading books, completed books, and reading progress.
- **Delete Books:** Remove books from the reading list.
- **Persistent Storage:** Uses browser local storage to retain saved books after refreshing the page.
- **Responsive Interface:** Designed for a convenient user experience.

## 🛠️ Technologies Used

- CSS3
- JavaScript
- Browser Local Storage

## 🚀 How to Run Locally

1. Download or clone this repository.
2. Open the `book-reading-list` folder.
3. Open `index.html` in your web browser.

For a better development experience, you can open the project in Cursor or Visual Studio Code and run it using a local development server.

No backend server or API key is required for the current version.

## 💾 Data Storage

The application stores book information in the browser's local storage. Saved books remain available after refreshing the page in the same browser.

**Note:** Clearing browser storage or using a different browser may remove or hide the saved reading list.
